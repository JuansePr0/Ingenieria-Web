## Ejecución

1. Abrir `index.html` en un navegador.
2. Presionar `F12`.
3. Entrar a la pestaña **Console**.
4. Revisar los resultados de los ejercicios de las partes 1 y 2.
5. Para ejecutar la calculadora de la parte 3, descomentar en `index.html`:
   ```html
   <script src="calculadora.js"></script>
   ```
6. Recargar la página y seguir las instrucciones de los `prompt()`.
